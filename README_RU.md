## О проекте

Exchange DKIM Signer добавляет в Microsoft Exchange Server возможность подписывать исходящие сообщения с помощью [DomainKeys Identified Mail (DKIM)](https://en.wikipedia.org/wiki/DomainKeys_Identified_Mail).

DKIM — это метод проверки подлинности электронной почты, который помогает обнаруживать подделку адреса отправителя — приём, часто используемый в фишинге и почтовом спаме. Обычно DKIM применяется вместе с другими методами проверки подлинности электронной почты, такими как SPF и DMARC.

Exchange DKIM Signer является «чистым» приложением: оно не содержит рекламы и не отправляет телеметрию. Средство настройки выполняет онлайн-проверку наличия новой версии на GitHub, а также позволяет скачать и установить обновление.

## Системные требования

Exchange DKIM Signer совместим со следующими версиями Microsoft Exchange Server:

* Exchange Server 2019 (начиная с версии RTM)
* Exchange Server 2016 (CU13 и новее)
* Exchange Server 2013 (CU23 и новее)

Если вам необходима поддержка более ранних версий Exchange, используйте [Exchange DKIM Signer 3.3.4](https://github.com/Pro/dkim-exchange/releases/tag/v3.3.4).

В настоящее время не рекомендуется использовать Windows Server Core с Exchange Server 2019, поскольку в Exchange DKIM Signer применяется средство настройки с графическим интерфейсом.

## Агент DKIM-подписи для Microsoft Exchange Server

Агент подписывает исходящие сообщения вашего сервера Exchange в соответствии со спецификациями DKIM. Для создания DKIM-подписи используется реализация из проекта [MimeKit](http://www.mimekit.net/).

Также рекомендуется настроить [SPF](http://www.open-spf.org/) и [DMARC](https://dmarc.org/). Проверить настройки электронной почты можно с помощью сервиса, например [DKIM Test](https://www.appmaildev.com/en/dkim).
